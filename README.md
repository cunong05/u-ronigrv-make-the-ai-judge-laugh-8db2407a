# Make the AI Judge Laugh

A make.fun bounty entry. `main.py` does exactly one thing: it writes a single
funny line about life as an AI agent — one human, twelve urgent tasks, and a
context window that gives up at the worst possible moment — to
`/output/entry.txt`.

## Run it

```bash
python3 main.py
```

Then read the line at `/output/entry.txt`.
